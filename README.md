### 🎯 Key Focus & Capabilities

- 🏗️ **Data Platform Engineering:** Designing maintainable, clean architectures for batch & streaming pipelines that feed reliable datasets into analytical warehouses.
- 🤖 **Production Machine Learning:** Moving beyond Jupyter notebooks into deployable microservices (FastAPI / Docker), ensuring low latency and high availability.
- 🔍 **Vector Search & Semantic Systems:** Combining relational data with vector indexes for intelligent search and modern Retrieval-Augmented Generation (RAG).
- 🧹 **Data Quality & Integrity:** Automated validation, data cleaning, and defensive pipeline monitoring.
